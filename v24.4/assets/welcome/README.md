# Welcome imagery

These WebP images are real captures of the current `v119/` runtime, generated by
`tools/capture-v119-welcome.mjs`. No external or generated artwork is used.

- `market.webp`: seed 42, current trading floor cropped to `.pit-hall`.
- `build.webp`: seed 42, first project opened through the normal card action.
- `integration.webp`: a natural Cable Mania campaign fixture, connected using
  the current engine's select/rotate/place actions, cropped to the board.

Regenerate from the repository root:

```sh
NODE_PATH=/opt/codex/cua_node/lib/node_modules node tools/capture-v119-welcome.mjs
```

Requires the existing Playwright, Sharp and Chromium installation. Capture is a
maintenance command that overwrites these three images. Images total about 77 KB.
